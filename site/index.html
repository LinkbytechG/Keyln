Turn a tablet into a touch console for your Mac.

What it does

Actions

Open an app, activate a named window, send a keyboard shortcut, run a macOS Shortcut, run an approved Shell script, or chain steps into a sequential workflow.

Clear results

Each run shows whether the Mac received it, finished it, failed, or the result is unknown. Unknown results are never retried automatically.

Layouts & components

Keys, App groups, Action groups, swipeable Pages, a clock, text and recent activity, placed freely on a canvas. Export and import layouts; the Mac keeps a backup of the last valid one.

Themes & icons

Built-in and custom themes, key colours, real Mac app icons, a built-in icon set, your own PNG/WebP images, and optional Iconify search through the Mac.

Installable web app

Install it as a PWA on the device for a full-screen console. It is online-first; there is no offline mode.

Runs at login

A per-user background service starts with your Mac. A menu bar app shows status, starts and stops it, opens management login and shows a QR code of the address.

How it works

  1. Build and set up on the Mac

    Clone the repository, build it, then choose your Mac's private address. Setup creates a Keyln-only certificate authority and a server certificate for that address.

  2. Trust the Keyln certificate on your device

    Export the public CA certificate, compare its fingerprint, and install it as a trusted root on the tablet or phone. Never copy private keys.

  3. Pair and approve on the Mac

    Open the address on the device, enter a pairing code, then approve the request on the Mac. Knowing the code alone grants nothing.

npm ci --ignore-scripts && npm run build
npm run setup -- --address 192.168.1.20

Replace 192.168.1.20 with your Mac's private address. See the README for the full install guide.

Security

  • Local network only. The Mac listens on the address you chose, over HTTPS with its own certificate authority. Never forward the port through your router.
  • Approval on the Mac. A device can only join after you approve it on the Mac. Sessions use Secure, HttpOnly, SameSite=Strict cookies and last 30 days.
  • Actions by ID only. A device can only trigger actions already saved on the Mac. No endpoint accepts an arbitrary command, and scripts are approved on the Mac.
  • Management stays on the Mac. The /admin page only accepts connections from the Mac itself and needs its own short-lived login code.
  • One action at a time. Busy requests are rejected, not queued.

Requirements

A Mac with macOS 13 or later, Node.js 24 LTS or 26, the Xcode Command Line Tools, OpenSSL, and a device with a modern browser on the same private network.

Limitations

  • macOS only on the Mac side. Keyboard actions support the ABC / U.S. layout.
  • Helpers are ad-hoc signed, so macOS permissions may need to be granted again after rebuilding or upgrading Node.
  • Window matching uses exact titles; titles that change may not match.
