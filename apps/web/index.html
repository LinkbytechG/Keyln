Open Keyln through the Mac Host

Opening index.html directly does not start the console.

On the Mac, double-click Start-Keyln.command in the project folder, or run npm start there. Then open the HTTPS address shown in the startup terminal.

If you opened this page over HTTPS, check that the Host is running and restart it to load the latest build.

Keyln on this device

Install Keyln for an app icon and its own window. Your Mac must still be running and reachable on the local network.

  • Surface / Windows Edge: choose the install icon in the address bar, or the browser menu → Apps → Install Keyln.
  • Android: open this HTTPS address in Chrome, then use the browser menu → Install app / Add to Home screen.
  • iPad / iPhone: open this HTTPS address in Safari, then Share → Add to Home Screen. Enable Open as Web App if offered.

Keep this Mac address and its trusted certificate. Each installed app may need its own pairing. When the Mac is unreachable, execution stays disabled and no action is queued or resent.

Layout files

Export the saved Mac layout, including pages, keys and workflows. Files include non-secret script arguments; keep passwords and tokens out of your layout. Devices, certificates, script bodies and approvals are not exported.

Import starts with a preview. It does not execute actions or save automatically.

    Loading replaces any unsaved draft in this tab. Review and fix the imported draft, then Save layout and confirm replacement.

    Each save keeps the previous valid layout as a backup. Backup recovery is available in /admin on the Mac and revokes control-device authorization.
